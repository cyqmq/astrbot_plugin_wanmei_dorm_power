# 获取插件配置教程

本插件需要 4 个学校相关的核心参数：

| 参数 | 含义 | 来源 |
|---|---|---|
| `schoolcode` | 学校代码 | 缴费链接 `customerId=` 参数 |
| `payproid` | 用电缴费项目 ID | 账单 item 的 `id` |
| `businesstype` | 业务类型 | 账单 item 的 `flag`（用电一般为 2） |
| `api_url` | 云支付网关地址 | `https://<链接域名>/paygateway/smallpaygateway/trade` |

## 方法一：一键脚本（推荐）

仓库自带 `tools/detect_config.py`，粘贴一次缴费链接即可自动解析全部参数，还能搜索验证房间：

```bash
cd tools
python3 detect_config.py "https://cloudpaygateway.<学校域名>:<端口>/pay/index.html?...customerId=<学校代码>#/billDetail?item={...}"
```

脚本会：
1. 自动解析 `schoolcode` / `payproid` / `businesstype` / `api_url`；
2. 调用云支付接口验证学校代码是否有效（返回校区列表）；
3. 交互式引导你输入楼栋 → 楼层 → 房间号，找到并验证你的宿舍房间电量；
4. 输出可直接粘贴到 AstrBot 插件配置的完整配置块。

## 方法二：手动从链接解析

1. 在完美校园 App/小程序打开「用电支出」缴费页，把地址栏链接复制出来。
   链接形如：

   ```
   https://cloudpaygateway.<学校域名>:<端口>/pay/index.html?openId=...&token=...&customerId=<学校代码>#/billDetail?item={"id":<项目ID>,"flag":2,"payproname":"用电支出",...}
   ```

2. 从链接中提取：

   - **schoolcode**：`customerId=<学校代码>` → `<学校代码>`
   - **payproid**：`#/billDetail?item={...}` 里的 `"id":<项目ID>` → `<项目ID>`
   - **businesstype**：`"flag":2` → `2`
   - **api_url**：链接域名 + 路径 → `https://cloudpaygateway.<学校域名>:<端口>/paygateway/smallpaygateway/trade`

3. 填到 AstrBot 管理面板 → 插件配置。

## 方法三：抓包兜底

如果链接里看不到 `#/billDetail?item=`（比如入口不是 H5 缴费页），可以用浏览器开发者工具抓包：

1. 在电脑浏览器打开缴费页（或用手机浏览器调试模式），按 F12 打开开发者工具；
2. 切到 **Network（网络）** 面板，勾选 `Fetch/XHR`，清空日志；
3. 在页面上操作一次「选择宿舍房间 / 查询电费」；
4. 找到请求地址为 `.../paygateway/smallpaygateway/trade` 的 POST 请求；
5. 查看该请求的 Payload（负载），里面是一个 JSON：

   ```json
   {
     "method": "samllProgramGetRoomState",
     "bizcontent": "{\"payproid\":\"<项目ID>\",\"schoolcode\":\"<学校代码>\",\"roomverify\":\"<房间ID>\",\"businesstype\":\"2\"}",
     "timestamp": "...",
     "sourceId": 2
   }
   ```

6. 从 `bizcontent` 里取出 `payproid`、`schoolcode`、`businesstype`、`roomverify`（你的房间 ID）；
7. 请求的 URL 去掉路径后的部分即为 `api_url` 的域名，拼上 `/paygateway/smallpaygateway/trade`。

## 房间 ID 说明

`roomverify`（房间 ID）形如 `<校区ID>-<楼栋ID>--<楼层ID>-<房间号>`，由系统级联生成，含义为：

```
<校区ID>-<楼栋ID>--<楼层ID>-<房间号>
```

如果不想抓包，直接用聊天命令搜索：

```
/电量搜房 4栋 1层 101
```

会返回类似 `学生公寓4栋 1层 101房间 → <房间ID>`，再用 `/电量绑定 <房间ID>` 绑定即可。
